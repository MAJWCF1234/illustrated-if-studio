EMERGENCY / TECHNICAL - most players can ignore this folder
===========================================================

To play the game, go back one folder and double-click:

    Play the Game

Only open this folder if Play said something is missing, or if you're
helping someone debug.


IF PLAY SAYS SOMETHING IS MISSING
---------------------------------

1. Double-click:  SETUP-ADMIN.bat
2. Windows asks "Do you want to allow this app to make changes?" - click YES.
   (One-time install; needs the internet.)
3. When it finishes, go back up and double-click Play the Game again.


WHAT THESE FILES ARE
--------------------

SETUP-ADMIN.bat / SETUP-ADMIN.ps1
    Installs whatever this package needs (Node, Python, or C++ build tools).

_common.ps1
    Shared helpers for the setup scripts. Don't double-click this.

BUILD-EXE.*  (Python packages only)
    Optional: builds a standalone .exe. Technical; not needed to play.


STILL STUCK?
------------
Screenshot any error and send it to whoever gave you the game. They can also
run PLAY.bat in the main folder (black window) to see more detail.
