# Sample Project

A tiny, generic demo game bundled with **Illustrated IF Studio**. It exists so the
editor, exporters, players, and smoke tests have a project to run against without
depending on any specific game.

- Layout: `illustrated-if`
- Start scene: `start`
- Art: optional (`meta.artOptional: true`) — a placeholder `default.svg` is included.

Open it via the **Projects** tab or CLI (`use sample-project`), then build your own
game by adding scenes, characters, abilities, art, and audio.
